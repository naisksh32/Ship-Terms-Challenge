# 조선/해양 특화 언어모델 프로젝트

이 프로젝트는 조선 및 해양 분야의 전문 용어를 이해하고 생성할 수 있는 대규모 언어 모델(LLM)을 개발하는 것을 목표로 합니다. 데이터 수집 및 정제, 모델 파인튜닝, 그리고 실험적인 모델 배포를 위한 전체 파이프라인을 포함하고 있습니다.

## 프로젝트 구성

이 프로젝트는 세 가지 주요 구성 요소로 이루어져 있습니다:

1.  **[Word_Data](./Word_Data/): 데이터 파이프라인**
    *   해양 분야의 전문 용어 데이터를 수집, 정제하여 LLM 파인튜닝을 위한 데이터셋을 구축합니다.
    *   PDF, 웹사이트 등 다양한 소스에서 원시 데이터를 추출하고, 이를 표준화된 형식으로 클리닝합니다.
    *   최종적으로 모델 학습에 사용될 `train_data.jsonl`과 `test_data.jsonl` 파일을 생성합니다.

2.  **[Model](./Model/): 모델 파인튜닝**
    *   `Word_Data`에서 생성된 데이터셋을 사용하여 Gemma, Qwen 등의 최신 언어 모델을 파인튜닝합니다.
    *   LoMo (Low-Rank Modification)와 같은 효율적인 파인튜닝 기법을 실험하고, 최적의 하이퍼파라미터를 탐색합니다.
    *   파인튜닝된 모델들은 [Hugging Face Hub](https://huggingface.co/naisksh32)를 통해 공개되어 있습니다.

3.  **[llm-playground](./llm-playground/): 모델 실험 환경**
    *   파인튜닝된 모델을 실제로 테스트하고 상호작용할 수 있는 FastAPI 기반의 웹 환경을 제공합니다.
    *   Docker를 통해 간편하게 로컬 환경에 배포할 수 있으며, Ollama 및 Hugging Face Transformers 백엔드를 지원합니다.

## 전체 워크플로우

1.  **데이터 준비**: `Word_Data` 디렉토리의 스크립트를 사용하여 해양 전문 용어 데이터셋을 구축합니다.
2.  **모델 학습**: `Model` 디렉토리의 노트북과 스크립트를 활용하여 준비된 데이터셋으로 언어 모델을 파인튜닝합니다.
3.  **모델 실험**: `llm-playground`를 사용하여 파인튜닝된 모델의 성능을 검증하고 다양한 프롬프트를 실험합니다.

각 디렉토리의 `README.md` 파일에서 더 자세한 정보를 확인하실 수 있습니다.
